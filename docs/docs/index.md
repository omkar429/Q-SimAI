# Q-SimAI documentation!

## Description

**SemantiQ** is an AI and Deep Learning-based system that determines whether two questions are semantically similar or different. It uses **NLP and Transformer-based models such as BERT/SBERT** to understand the meaning of question pairs and generate a similarity score. The system can be used for **duplicate question detection, e-learning platforms, question banks, and automated assessment systems**.
